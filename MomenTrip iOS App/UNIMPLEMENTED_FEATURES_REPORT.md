# MomenTrip 미구현/부분구현 기능

## 구현 완료 또는 서버 연결 완료

- 회원가입, 로그인, 로그아웃
- 아이디 중복확인
- 서버 세션 기반 사용자 조회
- 프로필 이름/사용자 코드 저장
- 서버 계정 비밀번호 변경
- 여행 계획 저장 및 방 생성
- 방 목록 조회
- 초대코드로 여행방 입장
- 가입 사용자 기반 친구 검색
- 미션 목록 조회
- 사진 업로드
- 미션 완료 및 포인트 적립
- 미션 사진 4장 기반 프리미엄 스크랩북 다이어리 PNG 생성 및 다운로드
- 미션 사진 4장 기반 픽셀 네컷 포토부스 PNG 생성 및 다운로드
- 포인트 내역 조회
- 포인트의 지역화폐 전환 내역 저장
- 기억나유 월별 사진 캘린더
- 다이어리 저장
- 네컷사진 메타데이터 저장
- 공유 기록 저장
- 문의 등록 및 조회
- 충남 관광/음식점/지역화폐 추천 화면

## 부분 구현

- 사진 정확도/위치 정확도: 현재는 미션별 고정 점수입니다. 실제 AI 이미지 판별, GPS 검증, 위변조 방지는 없습니다.
- 같이가유 친구 기능: 가입 사용자 검색, 방 생성, 초대코드 입장은 가능하지만 친구 요청/수락/차단 관계는 없습니다.
- 초대 링크: 초대코드/링크 텍스트 복사는 가능하지만 유니버설 링크나 딥링크로 자동 입장하는 흐름은 없습니다.
- 네컷사진: 미션 사진 4장을 선택해 2번 컨셉 픽셀 네컷 PNG로 합성/export할 수 있습니다. 드래그 재정렬, 프레임 커스터마이즈 같은 고급 편집기는 아직 없습니다.
- SNS 공유: Web Share 또는 클립보드/공유 기록 저장 수준입니다. 카카오톡/인스타그램 같은 채널별 SDK 연동은 없습니다.
- 알림 설정: 앱 내부 설정 저장과 브라우저 알림 권한 요청만 있습니다. APNs 토큰 등록, 서버 발송, 예약 알림은 없습니다.
- 지역화폐 전환: 포인트 차감 거래 기록만 저장합니다. 실제 결제, 정산, 환불, 지역화폐 사업자 연동은 없습니다.
- 추천/관광 데이터: 충남 경량 샘플 데이터와 공개/대표 이미지 기반입니다. 공공데이터 실시간 API 또는 운영 관리 화면은 없습니다.

## 미구현

- 운영용 DB(Postgres/Firestore 운영 스키마 등)
- 운영용 이미지 스토리지(S3/Firebase Storage 등)
- HTTPS 배포 API 도메인
- 계정 삭제 및 개인정보 완전 삭제
- 친구 요청/수락/차단
- 유니버설 링크/딥링크 기반 초대 자동 입장
- 실제 지도/위치 SDK와 거리 검증
- AI 이미지 검증 모델 연동
- APNs 푸시 알림
- 네컷 고급 편집기
- 실제 지역화폐/결제/정산 연동
- 약관/개인정보처리방침 URL 및 App Store 제출용 정책 문서

## 배포 전 필수 작업

- 로컬 JSON DB를 운영 DB로 교체합니다.
- HTTP 로컬 API를 HTTPS API로 교체하고 iOS ATS 예외를 제거합니다.
- 업로드 파일을 운영 스토리지로 옮기고 용량/삭제/보관 정책을 둡니다.
- 금전성 기능은 정산, 취소, 악용 방지, 감사 로그를 구현하기 전까지 운영 노출하지 않습니다.
- 카메라/사진/알림 권한 문구를 App Store 심사 기준에 맞게 다시 점검합니다.
