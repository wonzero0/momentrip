# MomenTrip 미구현 기능 점검 보고서

## 1. 요약
- 전체 버튼/액션 개수: 61개(소스 기준)
- 정상 구현된 액션 개수: 45개
- 부분 구현된 액션 개수: 10개
- 미구현 액션 개수: 6개

## 2. 정상 구현된 기능
| 화면 | 기능 | 연결 상태 | 확인 근거 |
|---|---|---|---|
| 인트로 | 로그인/회원가입 이동 | 구현 | `IntroScreen`에서 화면 전환 |
| 로그인 | 로그인 | 구현 | `api.login` -> `/api/auth/login` |
| 회원가입 | 아이디 중복확인 | 구현 | `api.checkUsername` -> `/api/auth/check-username` |
| 회원가입 | 회원가입 | 구현 | `api.signup` -> `/api/auth/signup`, 사용자/세션/가입 보상 저장 |
| 메인 | 로그아웃 | 구현 | `api.logout` -> `/api/auth/logout` |
| 프로필 | 사용자 코드 복사 | 구현 | `navigator.clipboard.writeText` |
| 프로필 | 리워드 지갑 이동 | 구현 | `RewardsScreen` 이동 및 `/api/rewards` 조회 |
| 여행가유 | 혼자 여행 계획 저장 | 구현 | `api.createRoom` -> `/api/rooms` |
| 같이가유 | 방 생성 | 구현 | `api.createRoom` -> `/api/rooms` |
| 같이가유 | 방 목록 표시 | 구현 | `api.rooms` -> `/api/rooms` |
| 미션 | 미션 목록 조회 | 구현 | `api.missions` -> `/api/missions` |
| 미션 | 사진 업로드 | 구현 | 웹 파일 업로드 및 Capacitor Camera 업로드 |
| 미션 | 미션 완료/리워드 적립 | 구현 | `/api/missions/:id/complete`, `rewardTransactions` 저장 |
| 기억나유 | 월 이동 | 구현 | 현재 월 상태 기반 이전/다음 달 이동 |
| 기억나유 | 여행 사진 업로드 | 구현 | `/api/photos`, 서버 업로드 파일 및 DB 저장 |

| 기억나유 | 사진 공유 기록 | 구현 | Web Share/clipboard 후 `/api/share` 저장 |
| 다이어리 | 다이어리 저장/수정 | 구현 | `/api/diaries` POST/PUT |
| 다이어리 | 다이어리 공유 기록 | 구현 | Web Share/clipboard 후 `/api/share` 저장 |
| 네컷사진 | 사진 4장 업로드 | 구현 | `/api/photos`, source `fourcut` |
| 네컷사진 | 네컷 저장/공유 기록 | 구현 | `/api/fourcuts`, `/api/share` |
| 리워드 | 잔액/거래 내역 조회 | 구현 | `/api/rewards` |

## 3. 부분 구현된 기능
| 화면 | 버튼/기능 | 현재 동작 | 부족한 부분 | 우선순위 |
|---|---|---|---|---|
| 뭐할까유 | J/P 추천 활동 | 화면 안에서 추천 목록 표시 | 사용자 선택/추천 결과가 서버에 저장되지 않음 | 중 |
| 여행가유 | 추천 여행지 전체보기 | 준비 중 안내 표시 | 추천 여행지 API/관리 데이터 없음 | 중 |
| 기억나유 | SNS 공유 | Web Share 또는 클립보드, 공유 기록 저장 | 플랫폼별 SNS 채널 선택/이미지 파일 공유 미구현 | 중 |
| 다이어리 | SNS 공유 | 텍스트 공유 및 공유 기록 저장 | 실제 SNS 채널 선택/공유 결과 검증 미구현 | 중 |
| 네컷사진 | 네컷사진 저장 | 사진 ID와 필터 메타데이터 저장 | 완성 이미지 합성/export `imageDataUrl` 생성 미구현 | 높음 |
| 같이가유 | 친구 목록 | 서버 API는 있으나 초기 목록은 비어 있음 | 친구 추가/검색/초대 수락/관계 저장 미구현 | 높음 |
| 같이가유 | 혼자 방 만들기 | 빈 친구 목록에서도 방 생성 가능 | 친구 기반 협업 기능은 아직 연결 전 | 중 |
| 회원가입 | 표시 이름 | 기본 표시 이름으로 가입 | 사용자가 이름/닉네임을 직접 입력하는 UI 없음 | 낮음 |
| 리워드 | 지갑 화면 | 잔액과 적립 내역 조회 | 사용/교환/출금 흐름 없음 | 높음 |
| 사진 업로드 | 파일 저장 | 로컬 서버 파일 저장 | 운영용 스토리지, 용량 제한 정책, 삭제 정책 미구현 | 높음 |

## 4. 미구현 기능
| 화면 | 버튼/기능 | 현재 상태 | 필요한 구현 | 우선순위 |
|---|---|---|---|---|
| 설정 | 계정 관리 | 준비 중 안내만 표시 | 프로필 수정, 비밀번호 변경, 계정 삭제 | 높음 |
| 설정 | 문의하기 | 준비 중 안내만 표시 | 문의 폼, 서버 저장 또는 이메일/CS 연동 | 중 |
| 설정 | 알림 설정 | 준비 중 안내만 표시 | iOS 권한 요청, 푸시 토큰 저장, 알림 선호도 API | 높음 |
| 설정 | 앱 정보 | 준비 중 안내만 표시 | 버전/약관/개인정보처리방침 화면 | 높음 |
| 같이가유 | 친구 초대/추가 | 친구 목록 empty state만 표시 | 사용자 코드 검색, 친구 요청, 수락/거절 API | 높음 |
| 리워드 | 리워드 사용/교환 | 버튼 없음, 읽기 전용 | 결제/정산/교환 정책과 거래 API | 높음 |

## 5. 배포 전 반드시 막아야 할 기능
- 리워드 사용/출금/교환: 실제 금전성 기능이므로 정책, 정산, 취소, 악용 방지 구현 전 노출 금지.
- 친구 초대/초대코드 외부 공유: 개인정보/초대 수락 흐름이 완성되기 전에는 empty state 또는 준비 중으로 유지.
- 알림 설정/푸시: Apple Push Notification 설정과 동의 기록 없이 활성화 금지.
- 계정 삭제/개인정보 수정: 실제 데이터 삭제 정책과 복구 정책 전에는 별도 화면 노출 금지.
- SNS 이미지 공유: 사용자 사진을 외부 전송하므로 명확한 사용자 액션과 권한 안내 필요.

## 6. 추천 처리 방식
- 바로 구현할 것: 친구 추가/검색 API, 계정 관리 기본 화면, 앱 정보/약관/개인정보처리방침 화면.
- 버튼은 남기되 disabled 처리할 것: 리워드 사용/출금/교환처럼 금전성 기능.
- “준비 중” 안내만 띄울 것: 추천 여행지 전체보기, 문의하기, 알림 설정.
- 아예 숨길 것: 실제 정산이 없는 리워드 교환/출금 버튼.
- 다음 버전으로 미룰 것: 추천 활동 개인화 저장, 네컷사진 이미지 합성 고도화, 플랫폼별 SNS 공유.
